# Vector World film template

Starting code for a new rich flat-vector explainer with Madhav's floating real-face presenter. It is
the quantum-computer film's final v6 code (`film-v6/` + `audio/v6/`), reorganised so the reusable kit is separate from that film's scenes. Copy this folder to
`<project>/film/`; never edit it in place. It typechecks as shipped (`npx tsc -p .`) with the quantum
example data in `src/`.

## Configure first (the only absolute paths)

| File | What to set |
|---|---|
| `pipeline_config.py` (Python tools) | `RAW_DIR` (camera card, read only), `TAKE_GLOB`, `TAKES`, `SRC_W/SRC_H/SRC_FPS` (ffprobe the takes), `HEAVY` (temp on D:), `CUDA_PY`, `YUNET`, `SFX_LIB` |
| `config.sh` (bash scripts) | `PY` (real Python 3.13, never `python3`), `CUDA_PY`, `HEAVY` / `HEAVY_WIN` (the same D: folder) |

Everything else derives from the film folder: `spine/` (spine scripts and outputs), `spine/takes/`
(per-take transcripts, gaze, sync), `<project>/audio/vo-real.wav` (gap-cut voice-over),
`HEAVY/matte/` (ProRes 4444 matte masters).

## Not included on purpose (generate per project)

- `node_modules/` (`npm install`, or junction a recent film's `node_modules` with the same package.json),
  `out/`, renders, ProRes masters.
- `public/vo.wav` (from `spine/vo-spine.wav`), `public/bed.wav` (`audio/mix.py`), `public/face/w<k>.webm`
  (`presenter/rebuild.sh`). No raw footage or audio of Madhav is ever copied into the skill.
- `src/words.json`, `src/vo_env.json`, `src/face-windows.json` are the quantum film's, kept only so the
  template typechecks and the example scenes resolve their cues. They are regenerated by
  `align.py` + `fix_words.py` and `presenter/face_windows.py`.

## Files

### Reusable kit and pipeline (keep; change only to improve them)
| File | What it is |
|---|---|
| `src/lib.ts` | easing (`prog`, `pop`, `mix`, `lerp`), `voLevel`, caption `chunk()` with the word-for-word check (throws on mismatch; `~word` = spoken, not shown) |
| `src/beats.ts` (top part) | `FPS`, `WORDS`, `cue(phrase, nth?)` (throws on missing or ambiguous phrase), `cueEnd`, `f()`, `SoundEvent`, `ev()` |
| `src/CaptionView.tsx` | sense-unit captions with word-timed highlight; centre layout (top 1362) or a side column ending 36 px before his face over the caption's whole span (`faceSpan`); hook captions condensed word by word; `HookTitle` (cover headline that thumps on his words) |
| `src/Film.tsx`, `src/Root.tsx`, `src/index.ts` | shell: scene for the current act inside `Finish`, cut glows, hook title, presenter, captions, `vo.wav` + `bed.wav` |
| `src/kit/avatar.tsx` | **real-face presenter**: per-window VP9-alpha clip in a `Sequence`, pop-in/exit, eased reframes and hard zoom cuts, feathered edges, body fade above `cutY`, rim + contact shadow, bob; `winAt`, `placeAt`, `faceBox`, `faceSpan` |
| `src/presenter-heygen/` | **fallback presenter** (HeyGen avatar, v5): one 25 fps clip mapped by time, placeholder silhouette until the clip exists. Swap the imports in Film/CaptionView/events to use it |
| `src/kit/camera.tsx` | `Camera` (keyed camera, log-space zoom, handheld, shake), `Layer` parallax, `toScreen`, `NearLayer` |
| `src/kit/finish.tsx` | bloom on bright things, vignette, moving grain (keeps dark gradients from banding after IG recompression) |
| `src/kit/palette.tsx` | palette `C` (indigo night world; gold / teal / coral meanings), fonts (Nunito, Barlow Condensed via `@remotion/google-fonts`), shared gradients and blur filters, `Stars`, `Leaf` |
| `src/kit/coin.tsx` | the hero coin (`Face`, `FlatCoin`, `SpinCoin`, `SpinArcs`): hand-drawn numerals, bead ring, foreshortened spin. Restyle or replace with the new film's hero object |
| `src/kit/room.tsx`, `life.tsx`, `props.tsx`, `objects.tsx` | the cosy night study (wall, window, night sky, plant, table, mug, near leaf, wall glow), life (steam, motes, desk lamp + light pool, whip blur, pulse), props (quantum chip, laptop, switch grid), objects (phone, molecule, padlock, dilution-fridge chandelier) |
| `src/transitions.ts` | `CUT_GLOWS`: a local glow carried across a cut at the pushed-through object (the entries are the quantum film's) |
| `src/events.ts`, `dump-events.mts` | collects every act's `EVENTS` + presenter in/out swishes; dumps `out/events.json` for the mixer and QA |
| `checks/*.mts` | caption check, face-bounds check, per-frame face-box dump (used by `presenter/faceqa.py`) |
| `spine/gapcut.py` | voice-over silence cut **only in word gaps** (> 0.30 s gap -> 0.24 s), then re-transcribes and fails on any word change |
| `spine/transcribe_takes.py`, `sync_wav.py` | per-take Whisper words; WAV <-> MP4 lag per take |
| `spine/build_spine.py` | splices voice-over stretches + chosen face pieces; tone (1/3-oct EQ) + loudness match; seam levelling; `splice-map.json`. The plan block (`FACE`, `VO`, `IN_AT`, `ORDER`) is per film |
| `spine/seams.py` | click and level-step check at every seam |
| `presenter/gaze.py`, `takesheet.py`, `facestrip.py` | YuNet yaw track; take frame sheets with yaw; dense face-crop strips for hands over the face |
| `presenter/matte.py` | RVM resnet50 on the GPU at native size, time-mapped per window -> ProRes 4444 masters |
| `presenter/mattesheet.py`, `measure.py`, `face_windows.py` | matte inspection (over purple / magenta / alpha / hair zoom); face/hair geometry; `src/face-windows.json` |
| `presenter/rebuild.sh` | everything downstream of the spine, in order (words, captions check, mattes, webm, geometry, tsc, events, face check, mix) |
| `presenter/faceqa.py` | zoom-cut strips and lip-sync strips (b/p/m onsets, -2..+3 frames) on the master |
| `presenter/heygen_measure.py` | alpha bbox / hair top of a HeyGen VP9-alpha clip (decoded with libvpx-vp9) |
| `align.py`, `fix_words.py` | Whisper alignment (+ `vo_env.json`); kept word fixes. `FIXES` and the envelope re-timing are per film |
| `audio/dsp.py`, `audio/designed.py` | DSP helpers and ~40 designed SFX |
| `audio/mix.py` (+ `snd_v5.py`) | score + SFX bed from `out/events.json`; phrase duck; 1-4 kHz FX-band duck. Score arrangement and the id -> sound map are per film |
| `render_ig.sh` | **delivery**: 1440x2560 via `--scale=1.3333333333333333`, ProRes in HEAVY, two-pass loudnorm + limiter, x264 crf 14 with maxrate from the duration (<= 300 MB), faststart |
| `render.sh` | quick 1080 review copy (bt709, faststart) |
| `qa.sh` | receipts + contact / cuts / presenter-window sheets + CTA Whisper |
| `snap.sh`, `sheet.py`, `board.py`, `dense.py`, `finalize.py` | stills + sheet; key-frame board (Windows font); dense fps-10 strips of a render; patch-splice a re-rendered range |

## Instantiate for a new video

1. Copy to `<project>/film/`, set `pipeline_config.py` + `config.sh`, `npm install` (or junction
   `node_modules`).
2. Voice-over: archive his untouched recording, then
   `py -3.13 spine/gapcut.py "<recording>.wav"`; fix mishearings in `<project>/audio/vo-real.words.json`
   by a kept script, never by hand.
3. Takes: `py -3.13 spine/transcribe_takes.py`, `py -3.13 spine/sync_wav.py`, `py -3.11 presenter/gaze.py`,
   `presenter/takesheet.py` / `facestrip.py` per candidate sentence; write `TAKES.md`.
4. Edit the plan block in `spine/build_spine.py`; `py -3.13 spine/build_spine.py`; `py -3.13 spine/seams.py`;
   large-v3 Whisper over `spine/vo-spine.wav`.
5. Matte test on 3-5 s (`$CUDA_PY presenter/matte.py test <take> <s> <e>`, `mattesheet.py`), then
   write `beats.ts`, `captions.ts`, `avatar-config.ts`, replace `scenes-example` with `src/scenes/`
   (update the imports in `Film.tsx` and `events.ts`), and run `./presenter/rebuild.sh`.
6. Stills (`./snap.sh`), key-frame board (`board.py`), review, then `./render_ig.sh <name>`,
   `./qa.sh`, `presenter/faceqa.py`. See `../reference/pipeline-commands.md` for every command.
