## Glossaire

- **ABP / APP / PBL** : action à ballon arrêté = coup de pied arrêté (traductions variables de l'espagnol *ABP*).
- **Phase initiale** : sortie de balle / construction depuis l'arrière.
- **SSP** : situations de simulation préférentielles (exercices conçus pour reproduire un contexte ou un objectif cognitif du jeu).
- **Rapports ABP** : avant-match (adversaire), in situ (pendant le match), après-match et cumulatif (propre équipe).
