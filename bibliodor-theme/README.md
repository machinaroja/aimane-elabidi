# Bibliodor — thème « Design 2026 »

Source du thème Shopify `Bibliodor — Design 2026`, créé à partir du thème
`Bibliodor — Trilogie IA + 3e offert`. Seuls les fichiers texte sont ici ; les images
(aperçus des pages, logos, polices) restent dans le thème Shopify.

Ce qui change :
- une seule feuille de style, `assets/bibliodor-2026.css`, à la place de `bibliodor.css`, `-v2` et `-v3` ;
- un panier latéral (`snippets/cart-drawer.liquid`) qui remplace le toast, le mini-panier flottant et la pastille d'offre ;
- l'ajout rapide au panier sur chaque carte de livre ;
- de nouvelles sections d'accueil : bande de garanties, trilogie IA, questions fréquentes ;
- les moyens de paiement dans le pied de page ;
- les animations clignotantes retirées (bandeau défilant, reflets, livres flottants).

Toutes les fonctions existantes restent : remise « 2 achetés, le 3ᵉ offert » et sa progression,
bloc trilogie IA de la fiche, pack, aperçu des pages, barre d'achat fixe, paiement express,
newsletter, données structurées.
