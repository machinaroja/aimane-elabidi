# Pages légales BIBLIODOR

Brouillons des quatre politiques de la boutique, à publier dans Shopify (Paramètres → Politiques) :

| Fichier | Politique Shopify |
|---|---|
| `mentions-legales.html` | Mentions légales |
| `conditions-de-vente.html` | Conditions générales de vente |
| `remboursement.html` | Politique de remboursement |
| `confidentialite.html` | Politique de confidentialité |

Les champs entre doubles accolades (`{{RAISON_SOCIALE}}`, `{{SIRET}}`…) reprennent l'identité de l'entreprise qui exploite aussi PILOTA90. Ils sont remplis à partir des politiques de PILOTA90, sans rien inventer.

Ces textes suivent le droit français applicable à la vente de contenus numériques : LCEN, Code de la consommation (notamment l'article L221-28 13° sur la rétractation) et RGPD. Faites-les relire par un professionnel du droit avant la mise en ligne définitive.
